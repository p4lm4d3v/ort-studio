# 🤡 ORT Studio: "Spas u zadnji čas"

Tebi i tvojoj ekipi sa faksa je muka od crtanja Karnoovih mapa ručno? Ne brinite, i name je. Napravili smo ovo "remek-delo" kako bismo preživeli **Osnove računarske tehnike (ORT)** bez gubitka živaca.

## 🚀 Šta ovo čudo zapravo radi?

* **Pravljenje tablica:** Nema više gubljenja vremena crtajući.
* **Karnoove mape:** Automatski ti ih iscrta dok ti pijes kafu (nažalost ne rešava ih).
* **CSV uvoz/izvoz:** Ako neko od kolega već ima rešene zadatke, samo ih "ukradi" (uvezi) i modifikuj.
* **Dizajn:** "Dark mode" da ne oslepiš dok učiš u 3 ujutru pred ispit.

## ⌨️ "Cheat Codes" (Prečice)

Ako želiš da deluješ kao haker pred kolegama, koristi ovo:

| Taster | Akcija |
| :--- | :--- |
| `Strelica Gore/Dole` | Menjaš broj ulaza (N) |
| `Strelica Desno/Levo` | Menjaš broj izlaza (M) |
| `Enter` | Generiše novu tabelu (Sve počinje ispočetka) |

## 🛠 Instalacija (za one koji ne znaju šta je terminal)

Samo raspakujte ZIP folder i pokrenite `ort_studio.exe`. Ne treba vam Python, ne trebaju vam biblioteke, ne treba vam pamet – samo pokreni i uživaj.
